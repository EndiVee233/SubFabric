# 字幕卡片「Quiet Card」原型

打开 [index.html](index.html) 即可（单文件、无外部依赖、无需构建）。

## 方向

把图二那种「外框 + 时间栏 + 竖线 + 中英分隔线 + 多组胶囊」的字幕卡，收成一张**内容优先**的卡片：

- **一个容器**：卡片表面 + 左侧 2px 角色色，不再套内层时间栏与分隔线。
- **三级层级**：中文 15/1.6、英文 12.5/1.62、元信息 9.5–10.5；时间用等宽数字、低对比。
- **状态按需出现**：播放中 = 呼吸点 + 文案；异常 = 琥珀图标；低置信 = 小百分比；选中 = 表面抬升 + 1px 亮边。
- **操作渐进披露**：悬停 / 聚焦出「重新识别 / 更多」；样式常驻；置信度、异常原因放在展开区。
- **角色去前缀**：角色名从正文 `[Wemmbu]` 提升为独立元信息，正文不再被名字截断；原型中保留可编辑文本。

## 交互

- 点卡片：选中；双击中文/英文：就地编辑（Enter 保存、Esc 取消、Shift+Enter 换行）。
- 悬停 / 聚焦：出现重识别与更多操作。
- 点异常图标：展开异常原因与重识别入口。
- 右上角：显示诊断、紧凑密度、对比旧版（隐藏/显示左侧旧版卡片）。
