WINDOWS UWP · CONTROL SUPPLEMENT

剩下的控件，也按磁贴语言补完

按钮在 UWP 下已经是磁贴。这一层补齐输入、选择、范围、列表、反馈与浮层：同源 Reveal、同一条 2px 直角、同一组 120–180ms。输入不做 3D，磁贴才下陷。

这是设计空壳：只演示控件语言与动效，不接入生产 editor；所有交互可点。

2px 直角#0078D7 固定蓝120–180ms 直线Reveal 只给可点表面
可点表面才有 Reveal

磁贴、卡片、行、菜单项、导航点亮面光与 2%+50% 描边；输入框只做四边等宽的 2px 焦点框，避免“输入框像按钮”。

2px / 1px / 12px

控件 1px 描边、2px 直角；Flyout 才用 12px 阴影；不做大圆角、不做外发光。

状态先变，位置少动

勾选/开关 120ms，焦点底线 160ms，抽屉 220ms；只动 opacity、transform、背景和宽度。
