# SubFabric 独立 UI 原型

## 请求与范围

2026-10-13：全盘重新设计 UI，交付不接入真实程序逻辑的完整前端空壳；所有页面、组件和交互流程可操作。
重新分类功能，建立清晰导航与信息架构。配色朴实简约；背景支持纯色、模糊流光、自定义图片；
通过材质、阴影、克制微动效、连续页面转场与回弹营造沉浸体验。用户授权子代理审查和评估设计。

仅在 `prototypes/subfabric-ui/` 创建独立原型，不修改或安装真实 editor、不连接真实 API、项目或设置。
原生 HTML/CSS/JS，无依赖或构建；所有长任务、模型与硬件结果为模拟。原型操作只存本浏览器独立命名空间。
不提交、不推送、不发布。连续性入口仍为 STATUS。

用户后续明确：聚焦桌面端；编辑器参照旧版截图的总体布局单独重做，主要改变 UI 并减少视觉复杂度。
独立入口 `editor.html`：左侧大预览，下方时间锚定备注与时间轴；右侧全高字幕面板，聚合字幕、角色、设置、日志。
编辑器不再常驻稿件库侧栏。识别辅助工具按需展开，字幕列表与播放画面保留主要空间；模拟功能与数据边界不变。

2026-10-13 后续主题需求：设置支持主题包选择、JSON 包导入导出和自定义主题色；内置 Studio 与 Material You。
Material You 采用动态色角色、花瓣/倾斜胶囊轮廓、波浪形播放进度条与轻回弹；主页借鉴参考图模块排版，仍为稿件功能。继续编辑卡片右侧使用可点击的 16:9 视频封面，花瓣加号几何居中，统计胶囊中的文字保持直立。
主题同时用于主页、其他原型页与独立编辑器，支持浅/深/系统与三种背景；保留编辑器布局。色彩生成使用本地色调算法，无外部依赖。

2026-10-13 进度条细化：按用户参考图，Material You 的任务与播放进度完成段在运行时显示动态波浪，剩余段为直线，使用圆形端点；暂停时两段均为直线。结束、等待、取消或失败也保持静态直线。
同一组件用于稿件卡片、活动横条、任务中心、模型下载与编辑器。固定波形只动画位移，屏外/后台/减少动效时停止；共享一个可见性观察器并释放离场节点。编辑器暂停或后台清除播放时钟，拖动与键盘定位继续使用原生 range。

## 信息架构

2026-10-13 编辑器操作回归：保留左侧影片、下方备注与时间轴、右侧字幕/角色/设置/日志；字幕卡采用左侧起止/时长与右侧双语文字，字幕块直接覆盖波形，只有覆盖范围轻微模糊。单行默认，双行模式按实际时间重叠分轨，超过两路时保留溢出轨以避免遮挡。角色按钮单击应用到已选字幕（未选时使用播放头所在字幕），右键或 Shift+F10 仅提供修改名称/颜色；支持取消、焦点恢复与撤销。新增不覆盖现有稿件的逐词示例独立入口，包含非等分的合成词时间、播放高亮、词边界拖动与键盘微调。

编辑器设置增加双行字幕轨、区域高度、平移灵敏度与缩放灵敏度，并在控件下解释用途。区域高度调节时间轴与影片的空间分配；平移数值控制每格滚轮移动的像素；缩放数值控制 Ctrl+滚轮每格倍率并保持指针下的时间位置。沿用旧方向：下滑查看更早，上滑查看更晚。设置保存到当前原型稿件；兼容旧浏览器状态，导入时验证范围与类型。继续仅使用合成数据，无真实媒体或识别接入。

- 稿件库：搜索、筛选、视图切换、文件夹、稿件详情、新建/导入、改名/复制/归档/删除与撤销。
- 稿件工作台：视频预览与播放、双语行内编辑、字幕/波形时间轴与拖拽、查找替换、批量操作、撤销/重做；
  右侧检查器聚合字幕样式、角色、翻译/重识别/逐词校对/反思纠错、备注；导入分段/区域字幕与导出。
- 任务中心：识别/翻译/处理/下载等活动和历史任务，暂停/继续/取消/重试、日志与进度；活动稿件始终优先。
- 资源中心：ASR/翻译模型、运行时与字体/样式预设；下载/使用/删除、LLM 方案编辑与连接模拟。
- 设置：通用/识别增强/下载与登录/性能/外观，包含背景、主题、动效与恢复示例。
- 帮助与诊断：快捷键、入门路径、运行日志与可导出诊断；全局命令搜索。
- 新建向导：来源 → 识别/翻译配置 → 确认；支持文件拖放、链接、项目包和示例，不发真实请求。

## 设计与动效

中性纸白、石墨文字、低饱和苔绿强调；材质以细描边、漫反射阴影、有限磨砂体现层级。
导航常驻，工作区随路径连续滑移，稿件封面与编辑预览共享视觉；弹层淡入与轻回弹，按压缩放，
列表短错峰、拖拽浮起与落位回弹。长动画不影响输入，减少动效偏好关闭位移与流光。
浅/深色与背景模式即时预览。所有危险动作可取消，键盘可操作，焦点明确，模态弹层管理焦点。
