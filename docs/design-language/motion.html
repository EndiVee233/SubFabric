三条曲线，三种性格

EASING

Classic 只用两条：--m-settle 负责"落定"（快起长尾，前 60% 走完 90% 的路）， --m-exit 负责"离开"（加速离去，绝不拖尾）。第三条是 Material 的回弹，Classic 不采用。

settle · 落定cubic-bezier(.16,.84,.28,1)
入场 / 展开 / 线生长。肉眼看是"很快就位，然后停住"。
exit · 离开cubic-bezier(.4,0,.6,1)
退出。先慢后快，走的时候不留在原地。
back · 回弹（不采用）cubic-bezier(.34,1.4,.64,1)
Material 的弹性。Classic 不用——回弹会让"排版"变成"玩具"。

动效必须可关

REDUCED MOTION

跟随系统 prefers-reduced-motion，另提供应用内开关（设置 → 外观 → 减少动效）。 关闭后不是"变快"，而是一帧到位：所有入场直接呈现终态，只保留颜色与边框过渡。

减少动效　　打开这个开关，本页所有动画与过渡都会压到 1ms，用来验证终态是否可读。

这套动效已实装在 classic-shell.html：首页与编辑器的入场错峰、侧栏规则线滑移、 页签下划线、Toast 下落，都是同一组令牌驱动的。切换「旧 Classic / Classic / Windows 10」可以看到 旧版几乎没有动效（且被 transform:none!important 关掉），Windows 10 则是纯淡入。
