# SubFabric 设计语言

> **阅读提示（2026-10-20 补记）**：本文整理的是这套样式表**所描述/所声称**的设计语言，
> 六条原则在通用层（Studio 骨架、UWP、Material）成立。
> 但 **SubFabric Classic 方言本身并未落实其中多数原则**——它只有 22 行独占规则，
> 分层失效（1.06:1）、强调色被引用 438 次、18 种圆角、并显式关掉了位移动效。
> Classic 的实际问题与证据见 `docs/design-language/CRITIQUE.md`（可视化：`why-classic-fails.html`）。

> 依据仓库 `EndiVee233/SubFabric@8f2213d` 的 `editor/css/studio.css`（6127 行）、
> `editor/js/studio-themes.js`、`editor/js/icons.js`、`docs/THEME_PACKS.md`、`docs/PROJECT.md §4`
> 与内联设计注释反推。可视化样张见 `docs/design-language/index.html`。

## 0. 一句话定义

**一块深色的、会呼吸的字幕工作台**：把注意力全部让给画面与时间码，界面只用一条橙色左线、
三档灰和一档等宽数字说话。

产品是"长时间盯时间码"的工具，不是消费级视频编辑器。所有视觉决策都服从这个前提——
密度高、对比低、动效短、强调色面积小。

## 1. 六条骨架原则

### 1.1 一个强调色，一条竖线

全仓只有 `--accent` 一个强调色家族（含 `a07`–`a55` 十二档透明度），所有状态色都从它派生；
`theme.js` 按用户选的 seed 重算整族写在根节点，没设过就用默认橙 `#ff7a45`。

**"选中/播放"用左侧竖线表达，不用整块换色或加描边环。**

| 位置 | 表达方式 |
| --- | --- |
| 字幕卡 | `border-left: 3px` → 选中 4px 加粗 + `outline: 1px accent-a45` |
| 侧栏导航 | `::before` 3px 竖条，`top/bottom: 8px` 内缩 |
| 项目卡 | `::before` 3px 渐变条，hover 亮起 |
| 时间轴块 | 左边缘色块 |

理由写在 CSS 注释里：列表纵向滚动时，**左边缘是唯一稳定的"轨道"**，
横向位移会被 `overflow` 裁掉（曾用 `inset box-shadow` 补线，结果和 `border-left`
叠成"两条并排竖线"，被用户报 bug 后改为加粗既有边框）。

#### 3px 竖线的几何规则（2026-10-20 补）

圆角卡片上的竖线只有三种写法，选错就会出现"和框线重合但又不完全重合"：

| 写法 | 结果 | 评价 |
| --- | --- | --- |
| `border-left: 3px solid accent` | 线即边框，随外圆角一起弯 | **首选** |
| `box-shadow: inset 3px 0 0 accent` | 跟随内圆角（留 1px 边框） | 可用 |
| 伪元素满高矩形 + 父级 `overflow:hidden` | 被父级圆角裁切 | 可用 |
| 3px 宽伪元素 + `border-radius:12px` | **半径被按比例压到 1.5px，变成直角戳出圆角** | 禁止 |

原因：CSS 在圆角超过盒子尺寸时按比例缩放半径。一个 3px 宽的盒子给不出 12px 圆角，
再用 `left:0`（定位基准是 padding box）还会再内缩 1px —— 两点叠加就是"似是而非的双线"。
**结论：竖线不能是"贴在边框上的另一条线"，它得就是边框。**


### 1.2 两档文字，三级层级

文本只有三档，不做第四档灰：

| 令牌 | 深色值 | 用途 |
| --- | --- | --- |
| `--text-0` | `#eceef2` | 标题、正文、字幕主行 |
| `--text-1` | `#a8a8b4` | 次要说明、文件路径 |
| `--text-2` | `#6f6f7c` | 时间码标签、占位、元信息 |

因为产品核心是**中英双语逐词字幕**，字幕色单独成令牌，与 UI 灰阶隔离：

| 令牌 | 值 | 含义 |
| --- | --- | --- |
| `--zh` | `#ffffff` | 中文整句行（与 ASS 默认白一致） |
| `--en` | `#e9e9f0` | 英文整句行（比中文压一档，保留双轨层次） |
| `--lane-word` | `#8b7cf6` | 逐词轨道块 |
| `--main-sub` / `--sub-sub` | `#ffffff` / `#ffd54a` | 主/副字幕 |

### 1.3 细线分层，不压阴影

面板边界靠 **1px `--border`（`#2a2a34`）+ 顶部 2.2% 白色渐隐高光**（`--panel-top`），
不靠投影堆叠层次。阴影只给"真的浮起来的东西"：

```
--sh-1  0 1px 2px   rgba(0,0,0,.35)   /* 贴地卡片 */
--sh-2  0 6px 18px  rgba(0,0,0,.36)   /* 浮层 / 视频区 */
--sh-3  0 20px 52px rgba(0,0,0,.52)   /* 弹窗 */
--hair  rgba(255,255,255,.055)        /* 顶部高光细线 */
```

环境光是最底层两团 4.5%–7% 的 `radial-gradient`（accent + 冷蓝），
让"换主题色整机氛围跟着变"，但因为只有个位数透明度，不影响任何可读性。

### 1.4 圆角跟语义走

四档半径 + 胶囊，**容器越大圆角越大**：

```
--r-1  6px   标签、色块、小控件
--r-2  9px   输入框、次级按钮
--r-3 13px   卡片、视频区
--r-4 18px   大面板、提示卡
     999px   胶囊（筛选项、状态 badge、滑块）
```

外壳另有 `--sf-radius: 18px` 作为默认方言，三套主题包各自压缩：
UWP 2–4px、Classic 6–8px、Material 24px + 999px。

### 1.5 动效：排版落定

Classic 的动效不是"浮起来"，而是**落定**——像活字被压到版面上：快起、长尾、不回弹。
另两套方言给出的答案是两种极端，Classic 刻意取中间偏静的位置：

| | Classic | Windows 10 | Material You |
| --- | --- | --- | --- |
| 入场 | **340ms · 5px 上落** | 180ms · 0px（只淡入） | 420ms · 12px 上浮 + scale |
| 错峰 | **24ms · 阅读序** | 24ms · 从下往上 | 45ms · 从上往下 |
| 缓动 | **settle（无回弹）** | linear | 带回弹 |
| 按压 | **scale .985** | 不位移，内阴影 | scale .92 + 形状 morph |
| 性格 | 排字 | 状态瞬变 | 空间与形变 |

**只动 `transform` / `opacity` / `color` / `box-shadow`，从不触发重排。**

| 时长 | 值 | 语义 |
| --- | --- | --- |
| `--dur-1` | 90ms | 按压、颜色反馈 |
| `--dur-2` | 150ms | hover、状态切换 |
| `--dur-3` | 240ms | 面板 / 页签 / 线滑移 |
| `--dur-4` | 340ms | 页面与列表落定 |

| 缓动 | 值 | 用途 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.2,.7,.25,1)` | 通用进出 |
| `--ease-out` | `cubic-bezier(.16,.84,.28,1)` | **落定**：快起长尾，前 60% 走完 90% 的路 |
| `--ease-exit` | `cubic-bezier(.4,0,.6,1)` | 退出：加速离开，不拖尾 |
| `--ease-back` | `cubic-bezier(.34,1.4,.64,1)` | 仅用于开关滑块等"落位" |

五条手感规则：

1. **位移一律 ≤6px**，只有"可点元素按压"才缩放（`.985`，不是 `.97`）。
2. **入场淡出比位移先结束**：opacity 在前 62% 到 1，位移走完整条长尾。
3. **不回弹**。唯一的过冲是数字落定的 1px，肉眼几乎不可见。
4. **线从上方/左方生长，永不从中间展开**；能滑移的元素只有"同一条线"（导航规则线、页签下划线），内容不飞。
5. `prefers-reduced-motion` 下**一帧到位**：所有入场直接呈现终态，只保留颜色与边框过渡。

### 1.6 一套图标，一种笔触

24×24 网格、`stroke-width: 1.9`、`round` 线帽线接、`fill: none`、`stroke: currentColor`；
默认渲染 14px，导航 18px，字标 17px，空态 40–46px。

**明确拒绝 emoji**，理由写在 `icons.js` 头部：emoji 是各机器不同的彩色贴图，
字重、留白、基线都不受控，一排按钮里混着 📁📄💾 会"显得拼凑"。
未知图标名返回空串而不是 `undefined`——宁可缺一个图标，也不破坏 DOM。

## 3. 版式与密度

### 3.1 字体栈

```css
/* UI */  "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif
/* 数字 */ "Cascadia Mono", "Consolas", "SFMono-Regular", ui-monospace, monospace
```

### 3.2 字号阶梯（实测使用频次）

| 字号 | 出现次数 | 角色 |
| --- | --- | --- |
| 12px | 114 | **正文主力**（列表、设置项、按钮） |
| 11px | 94 | 次级说明 |
| 13px | 54 | 强调正文 / 外壳基准 |
| 10px | 43 | 元信息、眉标 |
| 9px | 20 | 最小可用：badge、时间戳标签 |
| 14–16px | 31 | 卡片标题 |
| 18–30px | 17 | 页面标题（首页 30px） |

**基准 13px（外壳）/ 14px（旧编辑器）**，不是 16px。
32px 以上的字号只出现在首页大标题与统计数字，属于"仪表盘"，不属于工作区。

### 3.3 字重

`400` 正文 / `500` 次级标题 / `550` 卡片标题 / `600` 按钮与强调 / `700` 字标。
没有 800/900；`300` 只在超大号数字上出现。

### 3.4 数字必须等宽

时间码、百分比、重试次数、保存态一律：

```css
font-variant-numeric: tabular-nums;
font-family: var(--mono);
letter-spacing: -.2px;
```

否则进度跳动时数字会左右抖，是这类工具最刺眼的缺陷。

### 3.5 布局骨架

```
侧栏 218px（--sf-nav-w）  固定、blur(18px)、右描边
顶栏  72px（--sf-top-h）  固定、面包屑、11px muted
内容  max-width 1360px，内边距 34px
项目网格 3 列 / 20px gap；卡片封面 16:9
```

编辑器工作区是 **3 区网格 + 可拖动分割线**：

```
50px   工具栏
1fr    舞台（视频）      6px   6px
232px  时间轴           竖分割  字幕列表 400px
```

分割线本体 6px、视觉只画中间 2px，hover 时变 accent——**可发现但不占视觉重量**。

## 4. 组件语言

### 4.1 按钮

```
高度 32px / 圆角 10px / 内边距 8×13 / 描边 1px var(--line) / 背景 var(--surface)
hover: 背景 surface-2 + 边框 accent + translateY(-1px)
active: scale(.96)
```

三种形态：default（实心 surface）、`btn-accent`（填充 accent + on-accent 文字）、
`btn-mini`（更矮的光晕阴影）。**主按钮永远只有一颗**，其余全是描边形态。

### 4.2 字幕卡 Quiet Card（本项目的签名组件）

```
grid: 76px 时间列 + 1fr 文本列，gap 9px
padding 9px 10px 9px 13px；margin 0 8px 6px；圆角 10px
border-left 3px var(--role, accent)
box-shadow 0 1px 1px rgba(0,0,0,.1)
```

- 左列只留**低对比时间值**，标签隐藏（`title` 保留）——因为一列只有 76px，
  中文标签和 `00:00:00.030` 挤同行会把"开始"压成竖排（实测 9×24 的标签矩形）。
- 选中：背景换 `--cc-bg-selected`、边线换强线、**左边框不加宽**（Classic 分支）；
  旧版 3px→4px 平滑加粗的动画被收掉，因为它会推挤文本列 1px。
- 角色色通过 `--role` 注入，卡片本身不认识"角色"这个概念。

### 4.3 首页 Hero 三段式（品牌识别）

```
[花朵/时钟 102×102, r28]  [续作卡 弹性宽度, r24, accent-soft]  [胶囊 110×148, rotate(40deg)]
```

三件几何体：**圆角方（花）、大圆角横卡、旋转 40° 的胶囊**。
这是 SubFabric 最容易识别的版式签名——抽象、非写实、无插画。
Material 方言里花朵变成 SVG 时钟（指针用 accent 描边），其余不动。

### 4.4 输入 / 开关 / 滑块

- 输入：32px 高、9–10px 圆角、`surface` 底、聚焦 `outline: 2px accent, offset 3px`。
- 开关：`--ease-back` 位移 18px + `scale(1.04)`；打开态滑块贴右内边（内边距 2px）。
- 滑块 thumb：hover `scale(1.12)`、active `scale(1.22)` + 6px accent 光环。

### 4.5 弹层

遮罩 `fade-in` 180ms + 对话框 `scale-in` 260ms（`.965 → 1`，上浮 10px）。
`pop-in` 用于菜单/提示，`--pop-ox/oy` 由 `util.popOrigin` 指向触发点——
**弹层从触发点长出来，而不是从屏幕中心**（Modal 例外）。

## 5. 主题包 = 换方言，不换骨架

同一套 DOM 与类名，靠 `body[data-design]` 与 token 覆盖切换四种方言。
主题包是 **纯声明式 JSON**：只允许白名单键、`#RRGGBB`、内嵌 PNG/JPEG/WebP，
**不能含脚本、CSS、HTML、SVG 或远程 URL**。

| 维度 | SubFabric Classic | Windows 10（默认） | Material You |
| --- | --- | --- | --- |
| 圆角 | 6–8px，卡片 16–20px | **2–4px 近直角** | 24px 卡片 / 999px 胶囊 |
| 材质 | 实心 surface | 实心 + `0 1px 3px #00000018` | 毛玻璃 + 环境色描边（rim） |
| 强调色 | 橙 `#ff7a45`，可自定义 | Win10 蓝 `#0078D7`，**禁止自定义** | seed 推导 Material 角色色 |
| 动效 | 120ms 直线过渡 | 120–180ms，`transform: none` | spring + 波浪进度条 + 错峰入场 |
| 形状签名 | 左侧 3px 强调条 | 磁贴（tile）方片 | 播放键 squircle `50% 50% 12px 50%`，随状态 morph 到 16/18px |

token 覆盖之上还有一层**运行时色板推导**：

1. `hueSeed()` 取 seed 的色相与饱和度（饱和度夹在 .24–.7）
2. `tone()` 用近似 HSL 调色生成 bg / surface / container / line
3. `readable()` 逐格加减明度，直到对比度 **≥ 4.6:1** 才停
4. `--on-accent` 按 `contrast() ≥ 4.5` 在 `#ffffff` 与 `#101318` 之间二选一

所以"用户随便选个主题色也不会出现白字白底"是算法保证的，不是人肉挑的。

> 注：`studio-themes.js` 注释明说这是 "inspired by Material color roles; not the Google HCT algorithm"——
> 刻意不引第三方依赖，132 行纯函数跑完。

## 6. 反模式清单（从修 bug 记录里长出来的）

| 禁忌 | 原因 |
| --- | --- |
| 在已有 `border-left` 上再用 `inset box-shadow` 补线 | 两条线并排；inset 单独用是安全的，叠在边框上就多余 |
| 用 3px 宽伪元素 + 12px 圆角画竖条 | 半径被 CSS 按比例压缩成直角，戳出卡片圆角之外 |
| 列表卡 hover 用 `translateX` | 横向被 `overflow` 裁切，右边框消失 |
| 给 `#home-view` 加 `position: relative` | 它是全屏浮层，改完就盖不住编辑器，画面穿帮 |
| 给 `#video-stage` 改 `position: relative` | 会丢掉 `absolute; inset:0`，舞台退回 300×150 |
| 组件里散写时长/颜色 | 必须走 `--dur-*` / `--accent-aNN`，否则换主题色 / 降动效失效 |
| 用 emoji 当图标 | 跨机器字重留白不受控，视觉重量不一致 |
| 加第四档灰 | 三级灰已够表达，再加就让"哪个更重要"失去答案 |
| 大面积铺强调色 | 强调色是"指针"不是"底色"，面积大了会盖掉时间码 |

## 7. 一句话记忆点

> 深灰底、细线框、橙左线、等宽数字、120ms 回执。
> 界面永远退后一格，让字幕和画面站在前面。
