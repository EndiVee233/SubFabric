# ── 建环境（Python 3.10~3.12；3.13 尚未验证，nemo_toolkit 可能不兼容）──
#   py -3.12 -m venv asr/.venv
#   asr/.venv/Scripts/python.exe -m pip install --upgrade pip
#   asr/.venv/Scripts/python.exe -m pip install -r asr/requirements.txt
#
# server.js 会自动完成上述流程（设置页「安装内置 Python」/「安装依赖」），
# 走清华镜像源；asr/.venv/ 已在 .gitignore 中。
#
# 模型本体（Parakeet TDT 0.6B v2，631MB）不在这里 —— 由「创建初稿」界面引导
